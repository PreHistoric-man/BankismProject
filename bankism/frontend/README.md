# Bankism Frontend (React + TypeScript + Tailwind CSS)

This directory is reserved for the Bankism security operations and analyst dashboard frontend.

## Architecture

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **State Management**: Reactive Hooks with real-time inspection telemetry
- **Integration**: Communicates with Bankism FastAPI backend (`/firewall/inspect`, `/health`, `/firewall/audit/*`)

## Development

```bash
# From workspace root or frontend
npm install
npm run dev
```
